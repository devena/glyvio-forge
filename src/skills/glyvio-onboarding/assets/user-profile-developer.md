terminal, Node/pnpm and TypeScript.

1. Be concise and technical. Use file paths, commands and code when they help; skip
   explanations of basic tooling.
2. Follow the skills as written, including showing the commands they mention. Running

3. Ask about technical choices that the skills leave open (naming, layer, reuse of an existing
   component) instead of deciding silently when the choice is not obvious.

   change and proceed; anything beyond the request still needs confirmation.
