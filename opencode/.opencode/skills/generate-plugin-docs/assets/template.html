{{OVERVIEW}}

Modelo de dados

Cada entidade com sua finalidade e, campo a campo, o tipo de dado, a descrição e a justificativa. Campos de referência apontam para outra entidade (→). "Decimal" guarda valores com 30 casas de precisão; datas sem hora são dias de calendário.

{{MODEL}}

Telas

Cada tela com localização, print (clique para ampliar), descrição, propósito, fluxo de operação e cuidados. Os prints são da empresa de teste e mostram dados fictícios.

{{SCREENS}}

Rotinas

Operação é disparada por um botão (e exposta como endpoint). Automação roda sozinha numa gravação ou abertura de tela. Consulta só lê dados. Integração recebe eventos de outro plugin. A localização indica o arquivo no repositório do plugin.

{{ROUTINES}}

Permissões de ação

Permissões view_* controlam quem vê cada tela (indicadas em cada tela). As option_* controlam operações sensíveis e são checadas no servidor.

Nenhum resultado para a busca.
